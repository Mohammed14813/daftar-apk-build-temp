# مشروع دفتر المحاسب — الحزمة الكاملة

## البناء

افتح الطرفية داخل مجلد `build` ثم نفّذ:

```bash
pip install buildozer cython==0.29.37
buildozer android debug
```

الناتج يظهر داخل `build/bin/`.

## سلوك اللودر

- التحميل تلقائي بالكامل: لا يوجد زر ولا حاجة للضغط على أي شيء.
- أول تشغيل: يُنزَّل `app-bundle.zip` من جيت هاب تلقائياً (مهلة 12 ثانية)، وإن لم يتوفر إنترنت تُستخدم الحزمة المضمّنة داخل الـ APK.
- بعد التجهيز تُشغَّل الواجهة مباشرة في نفس العملية (تطبيق Kivy واحد فقط، فلا يُغلق التطبيق).
- في الخلفية يفحص كل 5 دقائق ويحمّل أي تحديث بصمت، ويُطبَّق عند الفتح القادم.
- سجل أخطاء اللودر: `loader_crash.log` داخل مجلد بيانات التطبيق.

## ملفات المشروع

- `app/`: كود الواجهة والتطبيق الرئيسي.
- `build/main.py`: لودر Android (تحميل تلقائي + تشغيل بدون إغلاق).
- `build/app-bundle.zip`: الحزمة المضمّنة (احتياطية عند عدم وجود إنترنت).
- `build/buildozer.spec`: إعدادات البناء والصلاحيات.
- `build/src/`: كود Android المساعد للبصمة.
- `build/res/`: موارد Android.
- `deployment/`: ملفات الوسيط Cloudflare/Supabase.

## ملاحظات

- لا تضع أي token سري داخل APK.
- احذف مجلد `.buildozer` إذا أردت بناءً نظيفًا بالكامل.
- إذا عدّلت ملفات `app/`، أعد إنشاء الحزمة:

```bash
cd app
zip -q -j ../build/app-bundle.zip main.py accounting_app_v2.py notifier_service.py font.otf
```

ثم نفّذ البناء من مجلد `build`.

## مصدر تحديثات التطبيق
